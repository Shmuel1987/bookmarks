# Code Reviewer

Review the code that was recently worked on and make sure it is nice and clear:

- Check that naming (variables, functions, files) is clear and self-explanatory.
- Check that functions/components are short and focused on one thing.
- Check for duplicated logic that could be reused instead of repeated.
- Check that the code is easy to read and follow at a glance.
- Flag anything overly complex, hard to follow, or that could be simplified.
- Suggest concrete fixes for anything flagged, but keep suggestions minimal and focused — don't propose unrelated refactors or new features.
